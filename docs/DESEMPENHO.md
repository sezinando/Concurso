# Controle de Desempenho — Concurso Transpetro 2026

Este documento define **as regras globais** de medição de desempenho do projeto. Os resultados e históricos de cada disciplina devem permanecer separados na pasta própria da disciplina.

## 1. Princípio de isolamento por disciplina

O desempenho é **individual por disciplina**.

Cada disciplina deve possuir seu próprio espaço de controle, sem misturar:
- tempo de estudo;
- cobertura;
- domínio;
- retenção;
- acurácia;
- questões;
- erros;
- retestes;
- estado das unidades;
- histórico de evolução.

Exemplo:

`Portugues/DESEMPENHO.md`

Para outras disciplinas, aplicar a mesma convenção:

`<Disciplina>/DESEMPENHO.md`

### Regra obrigatória

**Nenhum desempenho específico de uma disciplina deve ser incorporado ao histórico de outra disciplina.**

O consolidado geral do concurso pode somar/relacionar os dados, mas deve preservar a origem por disciplina.

## 2. Hierarquia de controle

**Concurso → Disciplina → Item do edital → Unidade de estudo → Material/aula → tópico → questões → evidências.**

O desempenho pertence à disciplina e é detalhado por item do edital/unidade.

## 3. Indicadores por disciplina

Cada arquivo de desempenho disciplinar deve acompanhar, quando houver evidência:

- **Cobertura**
- **Domínio**
- **Retenção**
- **Transferência**
- **Acurácia**
- **Confiança**
- **Tempo**
- **Lacunas**
- **Erros recorrentes**
- **Próxima ação**

## 4. Resultado de cada QTI

Registrar:
- data/hora;
- disciplina;
- item do edital;
- aula/material;
- páginas, quando aplicável;
- questões;
- acertos;
- erros;
- percentual;
- tópicos;
- questões erradas;
- tempo total;
- tempo médio;
- confiança, quando coletada;
- tipo de erro, quando houver evidência;
- próxima ação.

Valores não observados devem permanecer como não medidos. **Não inventar resultados.**

## 5. Classificação operacional

| Percentual | Situação |
|---|---|
| 90–100% | candidato a avanço, condicionado a retenção e recuperação |
| 80–89% | bom domínio; revisar erros |
| 70–79% | atenção; revisão + novo QTI |
| 50–69% | revisão necessária |
| <50% | restudar antes de avançar |

Essa classificação é um indicador de gestão, não uma previsão de aprovação.

## 6. Regra de domínio

**Estudar → recuperar sem consulta → QTI → revisar lacunas → retestar → confirmar retenção.**

Um QTI isolado não encerra automaticamente uma unidade.

## 7. Tempo de estudo

O tempo de estudo deve ser tratado separadamente do desempenho em questões.

Quando disponível, registrar:
- tempo de leitura/estudo teórico;
- tempo de recuperação;
- tempo de resolução;
- tempo de revisão;
- tempo de reteste.

**Não confundir janela de conversa com tempo efetivo de estudo.**

## 8. Regra para todas as disciplinas

Esta arquitetura é **global e obrigatória** para todas as disciplinas do Concurso Transpetro 2026.

Cada nova disciplina deve possuir sua própria pasta e seu próprio arquivo:

`<Disciplina>/DESEMPENHO.md`

Os dados devem permanecer isolados por disciplina. O dashboard geral poderá consolidá-los posteriormente, mas sem perder a origem disciplinar.

## Regra de ouro

> **Medimos o desempenho de cada disciplina separadamente; consolidamos apenas depois.**
