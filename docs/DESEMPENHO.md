# Controle de Desempenho — Concurso Transpetro 2026

Este documento define como o projeto registra desempenho, domínio e avanço de conteúdo.

## Indicadores
- **Cobertura:** quanto do conteúdo previsto já foi estudado.
- **Domínio:** quanto do conteúdo estudado foi demonstrado em questões.
- **Retenção:** desempenho em retestes/revisões.
- **Lacunas:** conceitos que precisam de revisão.

## Resultado de cada QTI
Registrar: data/hora, contexto, disciplina, item do edital, aula/material, páginas, questões, acertos, erros, percentual, tópicos, questões erradas e tópicos com erro.

### Classificação operacional
| Percentual | Situação |
|---|---|
| 90–100% | Domínio para avanço |
| 80–89% | Bom domínio; revisar erros |
| 70–79% | Atenção; novo QTI após revisão |
| 50–69% | Revisão necessária |
| <50% | Restudar antes de avançar |

Essa classificação é um indicador de gestão, não previsão de aprovação.

## Regra de domínio
Estudar → recuperar sem consulta → QTI → revisar lacunas → retestar → confirmar retenção.

## Métricas
**Cobertura:** conteúdo concluído / conteúdo total × 100.

**Domínio:** unidades dominadas / unidades estudadas × 100.

**Progresso combinado:** Cobertura × 0,60 + Domínio global × 0,40.

A cobertura recebe maior peso porque mede o avanço pelo programa. O índice combinado é operacional.

## Estados
NAO_INICIADO · EM_ESTUDO · ESTUDADO · REVISAO · CONSOLIDADO

## Regra de atualização
- <70%: revisão.
- 70–89%: revisar erros + reteste.
- ≥90%: avanço, desde que o conteúdo também seja recuperado sem consulta.

## Registro
Cada QTI deverá gerar um registro estruturado. Valores de desempenho só podem ser preenchidos quando observados; não inventar resultados.

## Objetivo do painel
Responder: quanto estudei, quanto domino, onde estão minhas lacunas, último desempenho, evolução e quanto falta para concluir o programa.
