# Concurso Transpetro 2026 — Sistema de Estudos

Este repositório centraliza o controle de progresso, desempenho, questões interativas e a camada de aprendizagem baseada em evidências.

## Documentação principal

- PROGRESSO.md — estado atual do estudo e mapeamento do edital.
- docs/INDEX.md — índice geral.
- docs/LEARNING_SCIENCE_CONSOLIDADO.md — consolidação da pesquisa acadêmica e comunitária.
- docs/LEARNING_SCIENCE_SOURCES.md — fontes e evidências.
- docs/GUIA_OPERACIONAL_ESTUDO.md — guia prático de estudo.
- docs/ARQUITETURA_APRENDIZAGEM.md — modelo técnico do sistema adaptativo.
- docs/CONTROLE_PROGRESSO.md — controle por unidades.
- docs/DESEMPENHO.md — métricas e diagnóstico.
- qti/README.md — motor de quiz interativo.

## Princípio do projeto

Aprender → Recuperar → Testar → Corrigir → Espaçar → Misturar → Simular → Medir → Reaprender

A cobertura do edital e o domínio são métricas distintas.

## Uso por outros chats

Antes de propor um novo plano, simulado ou regra de revisão, consultar PROGRESSO.md, docs/DESEMPENHO.md, docs/LEARNING_SCIENCE_CONSOLIDADO.md e docs/GUIA_OPERACIONAL_ESTUDO.md.

Atualizações relevantes devem ser documentadas no repositório para preservar continuidade entre conversas.
